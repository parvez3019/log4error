Drafts for announcing 0.2.0. They're not published automatically; edit and post them yourself. Post **after** 0.2.0 is on Maven Central, so the starter coordinates resolve.

| File | Where | Suggested timing |
|------|-------|------------------|
| [awesome-java-pr.md](awesome-java-pr.md) | PR to akullpp/awesome-java (Logging) | Week 1 |
| [devto-fingers-crossed-logging.md](devto-fingers-crossed-logging.md) | dev.to / Hashnode / Medium (cross-post with canonical URL) | Weeks 2–3 |
| [reddit-r-java.md](reddit-r-java.md) | r/java, then r/springboot a few days later | Day the article goes live |
| [show-hn.md](show-hn.md) | Hacker News "Show HN" | Once, weeks 5–8, ideally with a real savings number |
| Newsletters | Java Weekly (Baeldung), foojay.io, Java Annotated Monthly, InfoQ Java | Send the article link with a 2-line summary |

Tips:
- Lead with the before/after log output and the "250× cheaper happy path" benchmark.
- Use the phrase **"fingers-crossed logging"**. People who know Monolog or Python's MemoryHandler search for it.
- Reply to every comment in the first few hours.
- If someone shares a use case, ask them to post it in Discussions → Show and tell.
