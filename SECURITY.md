# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| 0.0.x   | No        |

## Reporting a Vulnerability

Please report security issues privately by emailing **pha3019@gmail.com**.

Include a description of the issue, steps to reproduce, and impact if known.
You can expect an initial response within a few business days. If the report is
accepted, we will coordinate a fix and disclosure timing; if declined, we will
explain why.
